Download Clips_GTA

Official website: https://dannyelian.github.io/clips-app/

Clips_GTA is distributed as source you run locally. There is no cloud login on this page.

Get the software

  1. Install Node.js 18 or newer, ffmpeg, and Python 3.11 if you use face detection.
  2. Clone https://github.com/DannyElian/clips-app
  3. In the project folder run npm install.
  4. Start with ./servidor.sh on or npm start.
  5. Open http://localhost:8787 on the same computer.

TikTok (optional)

To publish from Clips_GTA you need TikTok developer credentials in a local .env file on your machine. OAuth returns to http://localhost:8787/api/tiktok/callback. See Privacy Policy for what that token is used for.
