Clips_GTA

Clips_GTA is desktop software for any kind of video: comedy, reactions, streams, gameplay, IRL, podcasts, or whatever you record. You import a file or a URL, Clips_GTA finds moments, exports vertical 9:16 MP4s, and can publish them to the TikTok account you connect.

Official Clips_GTA website: https://dannyelian.github.io/clips-app/

Desktop app Local processing TikTok Login Kit Content Posting API

What Clips_GTA is

Clips_GTA is not a social network, not a video host, and not a login wall. This website is the public product home for Clips_GTA: features, how to run the desktop app, support, Privacy Policy, and Terms of Service. The software itself runs on your computer (typically at http://localhost:8787 after you start it).

Typical session: open Clips_GTA, add one file or URL — or two sources (for example face + scene) — set clip length and count, export, then optionally tap TikTok on a clip. You stay the publisher of every video.

Layouts

Dual (face stacked over the main scene), full frame, or two videos stacked. Optional face detection can place a webcam pane.

Clip selection

Highlights from audio energy and scene changes, or even splits of a duration you choose. Quality targets: 360p, 720p, 1080p.

TikTok publish

OAuth Login Kit on desktop. Content Posting upload of files you exported. Tokens stay on the machine that runs Clips_GTA.

Sources

Local MP4/MKV/MOV/WEBM, or a YouTube/Twitch URL. Lives can rewind the last N minutes of DVR instead of clipping the live edge. Any genre.

How a job runs

  1. Start Clips_GTA on your computer (see Download).
  2. Open the Clips_GTA interface in your browser at the local address shown by the app.
  3. Paste a URL or drop a file (any type of clip source). Optionally add a second video.
  4. Choose duration, number of clips, quality, and highlights vs split.
  5. Wait for download (if URL), analysis, and export. MP4s appear under each job.
  6. Copy the suggested caption, or connect TikTok and publish from the same screen.

Frequently asked questions

Is this homepage a login page?

No. You can read the full Clips_GTA product, Download, Support, Privacy Policy, and Terms of Service without an account. TikTok sign-in happens inside the desktop app, not on this website.

Where are my videos stored?

On the computer that runs Clips_GTA, under that machine’s job folders. This website does not receive your VODs.

Who publishes to TikTok?

You do. Clips_GTA only uploads a file you exported after you grant TikTok permissions in Login Kit.
