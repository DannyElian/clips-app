How products and scopes work in Clips_GTA

Login Kit (Desktop): the user clicks Conectar TikTok. OAuth v2 with PKCE. Redirect URI http://localhost:8787/api/tiktok/callback. Tokens stay on the user’s machine.

user.info.basic: show the connected TikTok display name in Clips_GTA.

Content Posting API + video.publish: FILE_UPLOAD of clips the user exported, SELF_ONLY until audited.

video.upload: inbox fallback if direct post is not allowed.

We do not use Share Kit, Display API, or other scopes.
